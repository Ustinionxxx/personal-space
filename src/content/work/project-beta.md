## 项目概述

Project Beta 是一个集成到 GitHub PR 流程中的代码审查助手。

利用大语言模型分析代码变更，自动生成 review comments，帮助团队提高代码质量。

## 技术细节

- 基于 LangChain 的 Agent 框架
- GitHub Webhook 事件驱动
- 支持可配置的审查规则
